Problem definition

Up to three primary effects. Each is a noun-verb statement. No who, and no why.

Timeline

Shared events become candidate action causes for every primary effect that does not have its own timeline. The latest event is closest to the effect.

Evidence

Tag quality: Sensed (direct senses), Inferred (instruments, logs, calculations), Intuited, or Emotional. The chart shows a question mark when a cause has no match.
